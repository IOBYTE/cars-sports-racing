Generate raceline: ~/torcs_bin/bin/trackgen -c road -n torino -r
Generate shading: ~/torcs_bin/bin/accc +shad torino-shade-src.ac torino-shade.ac (shading file was manually edited)
Generate acc: ~/torcs_bin/bin/accc -g torino.acc -l0 torino-src.ac -l1 torino-shade.ac -l2 torino-trk-raceline.ac -d3 1000 -d2 500 -d1 300 -S 300 -es
