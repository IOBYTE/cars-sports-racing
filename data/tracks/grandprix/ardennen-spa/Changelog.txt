Version 0.9.1

Fixed the tribune floor, which was transparent when viewed from behind. Now it is double-sided
Added gravel on the right side of the track just after the next left turn after "Bruxelles".
Now the graphic file indicated in the track XML is ardennen-spa.ac instead of ardennen-spa.acc, because the second one has worse performance and shows errors with flickering and shadows in OSG. The .acc file is still provided for those who want to use it in SSG, because it includes the raceline prints. To use .acc edit the file ardennen-spa.xml by replacing
    <attstr name="3d description" val="ardennen-spa.ac" />
by
    <attstr name="3d description" val="ardennen-spa.acc" />
