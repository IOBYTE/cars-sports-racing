This is the readme file for the Bavaria G3-GTR Auto Graphics Black Livery for the regular Longday Series GT2 - Chris di Bona.

------------------------------------------------------

INSTALLATION

Note for Linux users:
- The default <installation path> is (at least, on Ubuntu):
  /usr/local/share/games/speed-dreams-2
- Be sure to have elevated privileges to install

To drive this car:
- Copy the contents of this folder to 
  <installation path>/cars/ls2-bavaria-g3gtr/

To enable it to Chris di Bona
- Copy yhe contents of this folder to:
  <installation path>/drivers/dandroid_ls2/1
- Remove the 'auto graphics black-' from the name of files to make it the default livery
