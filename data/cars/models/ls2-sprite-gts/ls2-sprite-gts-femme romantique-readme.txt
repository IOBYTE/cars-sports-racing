This is the readme file for the Sprite GTS Femme Romantique Livery for the regular Longday Series GT2 - Hank Iuliano.

Femme Romantique is a fictional Cosmetics Industry
------------------------------------------------------

INSTALLATION

Note for Linux users:
- The default <installation path> is (at least, on Ubuntu):
  /usr/local/share/games/speed-dreams-2
- Be sure to have elevated privileges to install

To drive this car:
- Copy the contents of this folder to 
  <installation path>/cars/ls2-sprite-gts/

To enable it to Hank Iuliano
- Copy the contents of this folder to:
  <installation path>/drivers/usr_ls2/4
- Remove the 'Femme Romantique-' from the name of files to make it the default livery
