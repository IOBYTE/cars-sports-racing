This is the readme file for the Boxer 96 RSR Gazzoil Livery for the regular Longday Series GT2 - Fabio Kon.

------------------------------------------------------

INSTALLATION

Note for Linux users:
- The default <installation path> is (at least, on Ubuntu):
  /usr/local/share/games/speed-dreams-2
- Be sure to have elevated privileges to install

To drive this car:
- Copy the contents of this folder to 
  <installation path>/cars/ls2-boxer-96rsr/

To enable it to Fabio Kon
- Copy yhe contents of this folder to:
  <installation path>/drivers/dandroid_ls2/5
- Remove the 'Gazzoil-' from the name of files to make it the default livery
