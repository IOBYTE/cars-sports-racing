This is the readme file for the Cavallo 360R Roxfall Livery for the regular Longday Series GT2 - Jim Jagielski.

------------------------------------------------------

INSTALLATION

Note for Linux users:
- The default <installation path> is (at least, on Ubuntu):
  /usr/local/share/games/speed-dreams-2
- Be sure to have elevated privileges to install

To drive this car:
- Copy the contents of this folder to 
  <installation path>/cars/ls2-cavallo-360r/

To enable it to Jim Jagielski
- Copy the contents of this folder to:
  <installation path>/drivers/dandroid_ls2/6
- Remove the 'Roxfall-' from the name of files to make it the default livery
